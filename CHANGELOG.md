# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows semantic versioning while it evolves toward a stable
`1.0.0` API.

## [Unreleased]

### Added

- CMake build system with install and package export support.
- Public namespace API: `libhid::GetHardwareId()`.
- Application-specific hardware IDs via `libhid::GetHardwareId(namespace)`.
- Compatibility wrapper for the older `LibHid` class API.
- Example executable that prints hardware IDs.
- CTest smoke test.
- GitHub Actions CI for Windows, Linux, and macOS.
- Documentation for hardware property sources and known limitations.
- Semantic versioning and breaking-change policy documentation.
- Install-from-source and downstream CMake consumption documentation.
- Release workflow for tagged builds with packaged artifacts and checksums.
- Compatibility policy for older `LibHid`, root `libhid.h`, and
  `SHAREDTESTLIB_EXPORT` names.
- CTest runtime environment setup for Windows MinGW builds.
- Project `.clang-format` style configuration.
- Unit tests for MD5 hashing and UUID formatting helpers.
- Include cleanup with more explicit standard-library dependencies.

### Changed

- Project layout now uses `include/`, `src/`, `examples/`, and `tests/`.
- Public export macros are generated by CMake.
- CMake is now the primary and only build system.
- Linux hardware detection now recognizes common `nvme`, `vd`, and `xvd` disk
  names and skips common virtual network interfaces.
- Smoke tests now have a timeout to avoid hanging indefinitely.

### Removed

- qmake project file.
